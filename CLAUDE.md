# CLAUDE.md — Mazz Laptop Hub public website

Public showcase site for Mazz Laptop Hub (`mazzlaptop.lk`). The admin system is in `../mazz-admin` (read its CLAUDE.md section 7 for which columns the site may use). Don't edit admin files from here.

## Rules
- **Read-only.** The site reads the admin's MySQL tables and never writes or migrates. There are no migrations here. Models throw on `save()` / `delete()`.
- Never load or show cost columns, `purchased_from`, `serial_number`, `notes`, batches, or any customer/order table. `Laptop` and `Part` limit every query to `PUBLIC_COLUMNS` (global scope in `App\Models\Concerns\Showcase`).
- `selling_price = 0` → "Ask for price". Laptops show when `is_published = 1` and status `in_stock`/`reserved`. Sold laptops are not listed.
- No Node on Hostinger: plain CSS/JS in `public/css`, `public/js`. No Vite.

## Stack
- Laravel 11, Blade, `config/mazz.php` (business details, media URL, Build slot order).
- `App\Support\Media::url()` builds photo URLs from `MAZZ_MEDIA_URL` (live: `https://admin.mazzlaptop.lk`) and prefers `.webp` when `MAZZ_MEDIA_PATH` points at the admin public folder.
- Pages: home, laptops, laptop detail, parts, part detail, build (`public/js/build.js`), contact.
- Build page (redesigned 2026-10-27): "Choose your items" with a progress bar; each row has a category icon (`HomeController::CATEGORY_ICONS`) that gets an orange tick when filled, "N options · from Rs. X", and a Choose pill. A chosen item shows as a small card (photo, specs, price, qty stepper, Change, trash). The picker is a right-side drawer (bottom sheet on phones) with search + price sort and Select buttons. White sticky summary card with photos, animated total, green "Send on WhatsApp", Copy link / Clear all, two trust lines; toasts confirm add/remove/copy. Pinned total bar on phones/tablets.
- Build page: one slot for a laptop, one per published part category. Total is an estimate; it sends the list to WhatsApp. State in `localStorage` (`mazzBuild`), shareable as `/build#b=l3,p1x2`; product pages link `/build#add=p1`.

## Local dev
- `.env` uses DB `mazz_site_demo`: a copy of the admin dump with some laptops published for previewing. The real local DB is `mazz-db`.
- MariaDB needs `DB_COLLATION=utf8mb4_unicode_ci`.
- `.claude/launch.json`: `mazz-site` (port 8010) and `admin-media` (port 8011, serves the admin's public folder for photos).

## Design
- **White body framed by dark sections** (Faraz, 2026-10-27): the hero, the coffee "Chat or visit" band and the footer are dark; everything else is white. Earlier: full light, full dark, Astral Luxe scroll, serif fonts, bento and WoodMart styles were tried. Goal: friendly, clean, easy for everyone; colour grading matters.
- `public/css/site.css` has **one token set**: light tokens on `:root`, and dark tokens redefined on `.hero, .band, .site-footer, .buildbar` and on the home header while it floats over the hero. Components use tokens only (`--text`, `--surface`, `--primary`/`--on-primary`, `--price`...), so they work on both. Don't hard-code light/dark colours in components.
- Light: `--bg #fff`, `--bg-2 #f5f6f8`, text `#14161a` / `#4b5160` / `#7d8391`, price `#c96a00`. Dark (graded from the hero photo): `#0a0b0e` / `#14171c`, text `#f2f3f5` / `#b3b8c1`, price `#ffad47`. Orange `#ff9919` is the single accent; green only for WhatsApp. `html` is dark so space under a short page matches the footer.
- **Logo: always the original `public/images/logo.png`**, never recoloured, no badge (Faraz's rule). It sits on the white header; over the dark hero and in the footer its slate text is low-contrast; ask the client for an official dark-background logo rather than making one.
- Header: logo left, text nav centred (hover/active = orange underline), round green WhatsApp icon right (no search, no phone number). **Dark (`#0a0b0e`) on every page** (Faraz, 2026-10-27, after trying white); on home it floats transparent over the hero and turns solid dark on scroll (`.is-scrolled`). The phone menu is a full-screen dark panel too: big links with arrows (current page orange with a dot), links fade in one by one, and a "Talk to us" block at the bottom (WhatsApp + Call buttons, address). The logo's slate "LAPTOP HUB" text is faint on it; an official dark-background logo would fix that. **No backdrop-filter** (it traps the fixed mobile menu).
- Home hero: near-black, Faraz's dark Dell desk photo `public/images/hero-dell-dark.webp` (1536) / `hero-dell-dark-sm.webp` (900) on the right (~64%), left and top edges masked into the black so the menu sits on clean dark (the earlier "DO MORE." photo `hero-dark*.webp` is kept to switch back); white headline with orange "Do More.".
